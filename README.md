# test_blockchain

Учебная реализация простого **блокчейна** на Python с веб-интерфейсом на **Flask**. Каждый блок хранится в виде отдельного JSON-файла, блоки связаны через хеш предыдущего блока, реализован упрощённый Proof-of-Work (PoW) и проверка целостности цепочки.

## Возможности

- **Добавление блока** — через веб-форму можно записать произвольный текст в новый блок цепочки, опционально сразу посчитав для него доказательство работы (PoW).
- **Проверка целостности цепочки** (`/check`) — пересчитывает хеши всех блоков и сверяет их с сохранённым `prev_hash` каждого следующего блока, помечая каждый блок как `ok` или `error`.
- **Майнинг** (`/mining`) — досчитывает Proof-of-Work для всех ещё не «намайненных» блоков цепочки.

## Как устроен блокчейн

- Каждый блок — это JSON-файл в папке `blocks/` с именем `<индекс>.json`, содержащий:
  - `text` — содержимое блока;
  - `prev_hash` — SHA-256 хеш предыдущего блока;
  - `timestamp` — время создания;
  - `proof` — число, найденное в ходе Proof-of-Work;
  - `index` — номер блока.
- **Proof-of-Work**: подбирается такое число `proof`, что SHA-256 от строки `<предыдущий proof><proof>` начинается с заданного количества нулей (`difficulty`).
- **Проверка целостности**: для каждого блока пересчитывается SHA-256 предыдущего файла и сравнивается с `prev_hash`, записанным в текущем блоке — если значения не совпадают, блок помечается как повреждённый.

## Стек

- Python 3
- [Flask](https://flask.palletsprojects.com/) — веб-интерфейс
- `hashlib` (SHA-256) — хеширование блоков
- Хранение данных — JSON-файлы в папке `blocks/`

## Установка

```bash
git clone https://github.com/xishe/test_blockchain
cd test_blockchain
pip install -r requirements.txt
```

Зависимости (`requirements.txt`):
```
blinker==1.6.2
click==8.1.3
Flask==2.3.1
itsdangerous==2.1.2
Jinja2==3.1.2
MarkupSafe==2.1.2
Werkzeug==2.3.2
```

## Запуск

```bash
python server.py
```

Приложение будет доступно по адресу:

```
http://127.0.0.1:5000/
```

## Структура проекта

```
test_blockchain/
├── server.py           # Flask-приложение: маршруты /, /check, /mining
├── blockchain.py         # логика блокчейна: запись блоков, PoW, проверка целостности
├── blocks/                # хранилище блоков (JSON-файлы), создаётся/пополняется автоматически
├── templates/              # HTML-шаблоны интерфейса
├── requirements.txt
└── README.md
```

## Примечание

Перед первым запуском в папке `blocks/` должен существовать хотя бы «генезис»-блок (`1.json` или аналогичный), так как `get_next_block()` ищет максимальный существующий индекс файла и создаёт следующий за ним — на пустой папке функция завершится с ошибкой.
